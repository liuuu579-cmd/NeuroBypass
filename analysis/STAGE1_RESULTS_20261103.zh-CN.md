- 所有旧文件保持原样。首次采样版本因重复前缀主动失败，保留失败证据并新增 v2；最终数据通过 BOS/内容前缀、重复和最新训练前缀检查。

## 关键解释

1. **最新 Transformer 现有权重在本次测试上明显失败，修正方向仍不足以恢复质量。** 标签约定决定 bottom-k 才是正确语义；反向 top-k 在这批数据上偶然更好不意味着原方向正确。K=6 时，修正 Router 在全序列 KL 上没有任何测试块优于校准静态；K=16 也只有 2/256 块更好。
2. **旧 RL 在 Layer-1 特征下表现为静态策略。** 256/256 块都输出 `[2,5,9,11,14,18]`。其全序列 KL 与校准静态几乎相同：逐块差值均值 +0.00014，配对 bootstrap 95% 区间为 [-0.00323, +0.00448]。这不是输入动态收益的证据。
3. **历史 raw token 特征下旧 RL 只有很小的组合变化。** 225/256（87.9%）块输出 `[2,5,7,9,11,14]`，其余两种组合分别出现 23、8 次。特征版本的差异需要在后续训练和评测中固定口径。
4. **修正后的新 Router 容易一起删除多个早期层。** K=6 的常见组为 `[2,3,4,5,6,9]`（67/256）。结合其质量下降，层间组合效应、独立 BCE 目标与少量文本覆盖是后续诊断方向；本轮不能单独确定各原因的贡献。
5. **K=16 的质量预算过于激进。** 连校准静态的 PPL 也从完整模型 17.586 增加到 41.083，不能因为能输出 16 个索引就认定这种剪枝比例可用。

配对不确定性估计见 [stage1_c4_statistics_20261103.json](stage1_c4_statistics_20261103.json)。它以 token 块为重采样单元，不能替代原始文档层面的独立性证明，也没有做多重比较校正。

## 静态校准结果

在独立的 8 个校准块上，以平均末 token KL 为目标、保护层 0/1 的迭代贪心路径为：

`[4,14,7,11,37,2,6,21,32,24,36,17,27,33,22,31]`

K=6 采用路径前 6 项，K=16 采用全部。这是小校准集上的贪心参考，不代表最强静态方法或全局最优；全序列 KL 与 PPL 是额外测试指标，并不是静态搜索的优化目标。

## 下一步的判断依据

暂不直接扩大现有 Transformer 的训练。先在 32 个测试块上计算逐输入迭代贪心参考，与当前固定静态组合比较，判断这两个预算上是否有足够的动态质量收益。保留完整路径与每步代价，用真实 KL 回答“理想一些的动态选择是否值得学”。这项逐输入搜索尚未运行，本轮没有生成新的训练标签或训练模型。

若逐输入参考显著更优，再用更多独立文本、按组切分、明确的 raw/Layer-1 特征口径和组合学习目标重建训练；如果参考提升很小，应优先研究强静态组合和较低 K。完整 PIQA 以及输入打乱消融仍是后续评测，不能将本次 C4 数字当作这些任务的结果。

数据局限：校准和测试是本地 C4 中不同区段的不重叠 token 块，已避开最新 v3 训练前缀，但没有证明原始文档互斥；旧特征数据缺少完整 token provenance，也不能穷尽排除历史重合。
