## 输入匹配：修复已验证，长后缀的质量收益还未分离

同一输入用自身路径和三次任务内置换路径比较。C4 全 100 条开发样本上，m=6、K=10 的 KL 从置换的 0.2579 降至自身路径的 0.2502，差值 0.0077（新配对复核 95% 区间 [0.0014, 0.0139]）。但在 66 条超过 128 token 的样本上，改善为 0.0067 [−0.0007, 0.0143]；再排除用于选检查点的样本，45 条上改善为 0.0065 [−0.0041, 0.0163]。K=12 的这些区间均跨零，m=6、K=10/12 的六项下游准确率置换区间也均跨零。

本轮同时更改训练数据、静态校准和观察窗口，无法把新旧结果的差异归因于第 128 个 token 之后的内容。下一步优先用同一新版检查点、同一长提示词和同一目标做 `完整提示词 / 前128 / 后128` 对照，基座三组都保留完整上下文，只改路由观察；另外在同长度区间置换，并保留独立的长样本。确认路由效益后，再在较深剪层档位比较动态与静态的等预算恢复微调。

## 部署：按需加载省显存，换层推高首 token 延迟

四个配置为 K10/128、K12/512、K10/1024 和 K12/1920，各模式每配置 8 次独立请求，每次生成 128 token。热请求时按需加载峰值 allocated 为 17.27–18.80 GiB，动态全常驻为 24.11–25.22 GiB，同 K 静态物理删层为 17.26–18.79 GiB。按需加载和动态全常驻在相同路由下的 logits 与生成哈希一致。

按需加载的热首 token 延迟为 0.49–1.02 秒，全常驻动态为 0.03–0.33 秒。按需端到端吞吐较完整模型快约 14–20%，但较同 K 静态物理删层慢约 13–18%；按需计入换层搬运，静态稳态测量排除了布局准备。最长配置（1920 token、K=12）按需 18.18 GiB、30.18 token/s、首 token 1.02 秒；全常驻动态 25.22 GiB、35.84 token/s、首 token 0.33 秒。这里是独立请求测量，不代表多轮连续复用或并发性能。
